# Electron 手動確認チェックリスト

`.claude/CLAUDE.md` の「UI 変更やゲームロジック変更は Electron で実際に確認してから完了とする」ルールに基づく、リファクタリング作業時の最低限の確認項目。

テスト基盤（`node --test`）が薄い間は、以下を各リファクタリングのコミット/フェーズ完了時に手動で実施する。

## チェック項目

- [ ] チュートリアルモードで1ステージをクリアできる
- [ ] プログラミングモード（`/programming`）でコードを実行してゴールできる
- [ ] プログラミングモードでプログラムをダウンロード → 再アップロードできる
- [ ] プログラミング（発展）モード（`/programming-exp`）で同様の操作ができる
- [ ] 対戦モード（`/match`）で CPU 対戦を1回最後まで実施し、勝敗表示が正しく出る
- [ ] 対戦終了後、同じ room_id で再戦できる（`match_room_store` が正しく後始末されている）
- [ ] 観戦モード（`/watching`）で対戦中のルームをリアルタイム観戦できる
- [ ] マップエディタ（`/map-editor`）でマップを作成しアップロードして遊べる
- [ ] 日本語(ja) / カタカナ(ja-k) の言語切り替えが各画面で文字化けなく表示される
- [ ] ブラウザ DevTools のコンソールにエラーが出ていない

## 実行方法

```
npm start
```

その後 Electron ウィンドウ、または `http://localhost:3000` をブラウザで開いて確認する。
